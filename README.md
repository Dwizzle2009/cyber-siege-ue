# Cyber Siege -- Unreal 5.8, first-person, Aeon native

The Aeon first-party FPS: a personnel-recovery campaign. Mission 1, *Bring Them Home*,
is the vertical slice and is built here as a gray-box first; art (MetaHuman people,
Epic's animation and city samples, contracted exosuit and rifle) lands on top of it.
Everything in this repo is code and data; the level is generated by a script.

## Mission 1 in one paragraph
Eight beats: insertion, the apartment block (six floors, the three squad commands),
the street (the mounted gun and the first AEGIS route), the wreck (meeting the crew),
the hold (four minutes, three approaches, Bell's clock), the save (AEGIS kills a mortar
team the squad can't reach), extraction (carrying two people through a collapsing route
to the rail yard), base (a walkable aftermath). The full script and bible live in the
Claude doc "Cyber Siege -- Design Bible".

## How the mission is built (`Source/CyberSiege/`)
| Piece | Files | What it does |
|---|---|---|
| Mission director | `Mission/CSMissionDirector` | Ordered beats, fired events, the named clock, confirm prompt, fail state, checkpoints (`USaveGame` + `?checkpoint` reopen) |
| Triggers | `Mission/CSMissionTrigger` | Boxes that advance a beat or fire an event: on enter, on dwell, or when an event has fired and the player is inside; gated by beat |
| Script | `Mission/CSMissionScript` | "When event X, do Y" rules: clocks, squad orders, rescuee states, kill-from-approach, hide/show tagged, teleport, presence, achievements |
| Dialogue | `Dialogue/CSDialogueSubsystem` | Plays `Content/Data/m01_Lines.csv` (imported as a DataTable): scripted lines by event with chaining, CutIf/OnlyIf, FireOnEnd; barks by trigger with cooldowns that yield to scripted lines |
| Squad | `Squad/CSSquadMate` | Bell, Chen, Mercer: follow formation, hold, move-to, breach, carry, scripted; shoot what they see; go down and get revived |
| Breach walls | `Squad/CSBreachWall` | Mercer's charge: fuse, blast on the far side, `<name>_armed` / `<name>_breached` events |
| Rescuees | `Squad/CSRescuee` | Reyes, Okafor, Halvorsen: trapped / waiting / following / carried / sheltered / aboard; mission fails if one dies |
| Enemies | `AI/CSEnemy`, `AI/CSCoverPoint` | Rifleman (cover-to-cover, bursts), Heavy (frontal shield 15% damage, melee), Gunner (static, long bursts); target the player, squad, exposed rescuees |
| Waves | `AI/CSWaveDirector`, `ACSSpawnPoint` | Waves on events from tagged approaches; weakest-approach pick; `open_<approach>`, `<cleared>`, `<reached>` events |
| Lens | `Lens/CSLensMarker` | AEGIS markers: objective, route, threat, strike (with the confirm), hold suggestions, labels; shown/hidden by events |
| Talk points | `Interact/CSTalkPoint` | Base-scene conversations; `talks_done` when every required one is used |
| Player | `CSPlayerCharacter` | First person, Enhanced Input in code; D-pad commands, LB lens, Y interact/revive/confirm; regen; checkpoint restart on death |
| HUD | `CSHUD` | Objective, clock, squad bars, subtitles, context prompt, lens overlay, fuse, fail card |

Mission 1 is data: the beat list on the director, the rule table on the script, the CSV,
and the actors `Tools/BootstrapMission1.py` places. No mission logic lives in C++.

## Build the gray-box
1. Build Development Editor (see "Build" below) and open the editor.
2. **File > Execute Python Script...** -> `Tools/BootstrapMission1.py`. It creates
   `/Game/Maps/M01_BringThemHome`, places every actor, and imports the dialogue table.
3. **Play.** `DefaultEngine.ini` already points the game at M01; the navmesh builds at runtime.
   Output Log lines tagged `[MISSION]`, `[WAVES]`, `[DIALOGUE]`, `[SCRIPT]` tell the story.

## What's in the box
- `Source/CyberSiege/` -- C++: player (first-person, Enhanced Input built in code),
  projectile, enemy, wave game mode, Canvas HUD, and **AeonSubsystem** -- the
  reference platform SDK (achievements, leaderboard, presence against the real API)
- `Config/` -- render config tuned for RX 9060 XT on Vulkan (see Docs/AEON_RENDER_TARGET.md)
- `Tools/BootstrapCyberArena.py` -- builds the arena map in the editor
- No `Content/` -- the script creates `/Game/Maps/CyberArena` and `/Game/Materials/*`

## Build (Windows, first time)
1. Epic Games Launcher -> install **Unreal Engine 5.8**. Tick **Linux** under Target Platforms.
2. Install the **Linux cross-compile toolchain** for 5.8 (linked from Epic's Linux docs).
   Verify: `echo %LINUX_MULTIARCH_ROOT%` prints a path.
3. Right-click `CyberSiege.uproject` -> **Generate Visual Studio project files**.
4. Open `CyberSiege.sln`, build **Development Editor / Win64**. (Needs VS 2022 with C++.)
5. Double-click `CyberSiege.uproject` -> editor opens, compiles shaders (first time is slow).

## Package for Aeon (Linux)
**Platforms > Linux > Package Project**, pick a folder. Output: `Linux/CyberSiege.sh` +
`Linux/CyberSiege/Binaries/Linux/CyberSiege`. Then:

    scp -r Linux wiz@Aeon:/home/wiz/aeon/games/cyber-siege-ue/
    # on the console:
    cat > ~/aeon/games/cyber-siege-ue/manifest.json << 'M'
    { "id": "CYBER-SIEGE-STD", "title": "Cyber Siege", "version": "0.2.0",
      "exec": "cd /home/wiz/aeon/games/cyber-siege-ue/Linux && ./CyberSiege.sh" }
    M
    pkill aeon-compositor

Vault -> Cyber Siege -> Play. The HUD's top-right shows **AEON LINK ONLINE** when the
game found the console's session; First Blood unlocks on your first kill and your score
posts to the leaderboard when you die.

## Aeon SDK notes (AeonSubsystem)
- Session: `AEON_TOKEN` env var, else `~/.config/aeon/auth.conf` `token=` (the console writes it)
- API: `AEON_API` env var, else `https://aeon-api-production.up.railway.app`
- Routes used: `POST /store/games/{sku}/achievements/{key}/unlock`,
  `POST /store/games/{sku}/leaderboard`, `PUT /presence`
- Achievement key `first_blood` must match the backend's key for this SKU -- verify
